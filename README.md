# 🚀 SMM Автоматизатор — "НейроСофт Гейминг"

Автономный ИИ-редактор для Telegram-канала, который скрейпит новости, оценивает их по 100-балльной шкале, адаптирует контент в хайповый стиль, убирает ИИ-слоп (AI-cliches) с помощью Humanizer-фильтра на базе 30 паттернов и автоматически публикует в Telegram-канал (или складывает в очередь на модерацию).

---

## 🛠️ Архитектура системы

- **Источники новостей**: HackerNews (Algolia API), Dev.to (API), Steam News (API), GamersNexus (RSS), GitHub (API Search).
- **Скор-анализатор (0-100)**: Оценка релевантности, свежести, виральности, уникальности и качества с помощью Gemini Flash.
- **Дедупликатор**: Точное совпадение по ID/URL + нечеткое (fuzzy) сравнение заголовков (difflib) во избежание дубликатов.
- **Генератор контента**: Адаптация стиля + **Pass 2: Humanizer** (30 правил очистки от AI-выражений типа *"следует отметить"*, *"в мире, где..."*, *"delve"* и пассивного залога).
- **Управление через Telegram Bot (FastAPI Webhook)**: Панель модератора с кнопками Approve/Reject, статистикой и возможностью ручного запуска.
- **Хранилище**: SQLite (локально) / PostgreSQL (Supabase в проде).
- **Автоматизация**: GitHub Actions (cron каждый час).

---

## 📋 Команды управления ботом

Отправьте команды боту модератору:
- `/status` — Посмотреть статистику базы данных и состояние автопубликации.
- `/queue` — Вывести список постов в очереди на модерацию с кнопками (✅ Опубликовать / ❌ Отклонить).
- `/pause` — Поставить автопубликацию на паузу (все посты с рейтингом 70+ будут идти в очередь).
- `/resume` — Снять с паузы (посты с рейтингом 85+ будут публиковаться в канал автоматически).
- `/force` — Запустить цикл сбора и обработки новостей прямо сейчас.

## ⚙️ Установка и запуск

### 1. Требования
- Python 3.11+

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Создайте файл `.env` на основе `.env.example`:
```ini
GEMINI_API_KEY=your_gemini_api_key_here
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
TELEGRAM_CHANNEL_ID=your_telegram_channel_id_or_username_here
```

### 4. Запуск тестов
```bash
python -m pytest
```

### 5. Ручной запуск сбора новостей
```bash
python -m smm_engine.main
```

### 6. Запуск Telegram Бота (Webhook)
```bash
uvicorn bot.app:app --host 0.0.0.0 --port 8000
```
Для работы вебхука в Telegram локально используйте `ngrok` или `localtunnel` и зарегистрируйте URL вебхука:
`https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<your-domain>/webhook`
